# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-08-22

### Added
- Initial release of Resume Portal Pro
- 7 multi-niche resume profiles (Amazon, Shopify, Admin VA, Customer Support, eBay, Data Management, Custom)
- 4 professional resume templates (Executive, Corporate, Minimalist, Tech)
- Complete export hub (PDF, Word, Plain Text, Print)
- Interactive profile editor with auto-save
- Portfolio showcase with lightbox viewer
- Section visibility manager
- Profile photo upload functionality
- PWA support and installation guide
- Bilingual UI (English/Tagalog)
- Responsive design for all devices
- LocalStorage persistence
- Dark mode control center with white resume canvas

### Technical Stack
- React 18 with Next.js 14
- TypeScript for type safety
- Tailwind CSS for styling
- Zustand for state management
- html2canvas & jsPDF for export
- React Hot Toast for notifications

### Features
- One-click niche switching
- Instant resume customization
- Live preview
- Professional export options
- Mobile-first responsive design
- Offline functionality ready
- PWA installable
